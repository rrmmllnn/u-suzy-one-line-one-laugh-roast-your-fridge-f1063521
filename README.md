One line, at most 200 characters, roasting a fridge — aimed at its ice maker,
not at the fridge ordering groceries or watching you eat.

## The line

> My fridge's ice maker mints one cube every forty minutes, then beeps at
> 3 a.m. to announce the vault is full: nine cubes.

Concrete and specific (ice maker, one cube every forty minutes, the 3 a.m.
beep), one clear twist that pays off in the last few words (the "vault" is
full — of nine cubes), and it reads cleanly aloud as a single line.

## Files

- `main.py` — the packed entrypoint (built with `makefun compress` from
  `line_src.py`, 312 bytes, at most 4,096 bytes). Run it and it writes
  `/output/entry.txt`.
- `line_src.py` — the readable source of the entry.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same 121-character line.
